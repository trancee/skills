# Rounds, incrementality, and lifecycle

Sources: [multiple rounds](https://kotlinlang.org/docs/ksp-multi-round.html), [incremental processing](https://kotlinlang.org/docs/ksp-incremental.html), and [KSP2 architecture](https://github.com/google/ksp/blob/main/docs/ksp2.md).

Each round includes existing sources plus generated files; `getNewFiles()` is prior-round output. `getSymbolsWithAnnotation()` returns symbols from new files plus previously deferred symbols. A round that generates no new files ends processing; remaining deferred symbols produce errors.

Return only deferrable source symbols from `process()`. Validate required error types and retry when another processor can generate them. Do not defer malformed user input, classpath defects, unsupported declarations, or a symbol already known impossible—log a precise error.

One processor instance spans rounds, but KS symbols/resolved types are round-scoped. Cache immutable names/paths/options, never `KSNode`/`KSType`/resolver-derived objects. Track generated output identities to prevent duplicate creation.

Incremental roots come from resolver root queries. KSP records resolution edges and output `Dependencies`. Aggregating outputs connect wider roots; isolating outputs connect only declared sources. Misclassification produces stale outputs or excessive rebuilds.

Verification matrix:
1. clean build snapshot of generated bytes
2. no-change build: KSP/compile tasks up-to-date or cache hit
3. change one annotated source
4. change one resolved dependency type
5. add/remove/rename annotated source
6. change processor option/classpath
7. compare each incremental output tree byte-for-byte with a clean rebuild

For defects set `ksp.incremental.log=true`; preserve `build/kspCaches/<source set>/logs/kspDirtySet.log` and `kspSourceToOutputs.log`. Use `ksp.incremental.log.graph.origin=<fq-name>` for DOT dependency graph. Restore incremental mode after diagnosis.

KSP2 runs in the Gradle daemon. Heap/debug flags belong to Gradle (`org.gradle.jvmargs`, `-Dorg.gradle.debug=true`).
